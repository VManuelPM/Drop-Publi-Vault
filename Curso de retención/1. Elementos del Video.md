# Hook

3 - 5 primeros segundos del vídeo que dan la primera impresión al espectador para que se quede.

Tienen que se buenos, bonitos, fuertes, intigrantes

- **Visualmente**: Enseñar algo sorprendente, satisfactorio, inesperado.
- **Lo verbal es muy fuerte**: Por ejemplo "Si tienes gasto no le des de comer esto"

Es la parte más importante de cada video.

## Tipo de Hook 1. El que te hace preguntar "¿Cómo llegó Ahí?"

- Se reserva la mejor toma del video para principio 
- Este hook funciona por que es impactante lo primero que se ve y genera intriga para saber **Como llegó ahi**

Normalmente cualquier problema se soluciona con 

1. Contexto
2. Confusión
3. Solución

Pero en. Instagram Reels suele funcionar mejor 

1. Confusión 
2. Contexto
3. Conclusión

Adelantar acontecimientos muchas veces estimula al espectador

## Tipo de Hook 2. El que te intriga a saber "A dónde quiere llegar"

Funciona cuando la premisa es muy inusual o intrigante mientras que el resultado es mas cotidiano y normal. Funciona más para videos educativos o simplemente cualquier medio informativo y transformativo, algo que sea mas util. Pero igual es para entretener.

Si quieres que algo complicado sea entretenido lo mejor es sorprender con algo inusual al principio y resolverlo al final.

Si empiezas la historia contando lo más divertido, vas a poder acaparar la atención que les dará la paciencia para escuchar lo más aburrido.


## Tipo de Hook 3. El que te hace pensar "Eso me pasa a mí jaja"

Se usan para resolver problemas, se usa para empatizar con la persona. 

Pensar en como empatizar con el cliente

En cuanto mas especifico, listo y astuto empaticemos con el cliente, más fácil es darle una solución. 


## Tipo de Hook 4. El que te hace dar cuenta "¿eso estuvo frente a mí todo este tiempo?"

La solución es inusual y se resuelve al final del video. Algo que mucha gente no sepa pero es cotidiano en su día.

Aquí voy a hacer que el cliente se de cuenta de un problema que tiene pero que no sabía que tenía. 

Se presentan nuevas perspectivas al usuario de como resolver el problema


## Consejos para ejecutar bien el Hook

1. **Combina lo verbal con lo visual** -> Haz que lo que se dice se complemente con lo que se ve, que no se repita. 
2. No digas literal lo que se puede ver, di algo relacionado con lo que se puede ver, que se complemente y ayude entre si para asi dar una imagen más rica en información.
3. **No sobreestimules** -> Asegurarse que lo que se dice vale la pena.
4. **Hazlo realista pero interesante** -> Tu hook no puede sonar demasiado bueno para ser verdad, debe de pasar la prueba del "y que". Tu hook no puede tener una respuesta obvia, predecible, ni de conocimiento general. Porque en ese caso, no podrás captar un interés. Ser honestos y realistas. La prueba del **¿Y Qué?** es para saber si nuestro hook tiene algo más de profundidad para retener al espectador. 
5. **Aprovecha el Texto**: Un texto en Instagram gana mucho tiempo entre leer y ver
6. **Aprovecha el movimiento y los objetos**: Si tienes un objeto que usar es mucho mas estimulante para la mente humana
