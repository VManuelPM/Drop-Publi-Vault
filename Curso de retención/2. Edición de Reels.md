# 1. Música 

- Si hay una canción suave y luego que explota.
- Inicio de la canción en el hook -> Luego un corte con la parte fuerte y rapida de la canción en el climax del hook para poder acelerar rapidamente el video

# 2. Risers y Wooshs

- Los dos sonidos más utiles para retener.
## 2.1. Risers

- Se usan para causar tensión y anticipación a que va a pasar.
- Perfecto para acortar en seco la musica 
- Perfecto para hacer que vuelva musica que no habia antes

## 2.2.Woosh (Sonido de viento cortado)

- Perfecto para cuando aparezca un elemento y no queda muy bien.
- Es bueno para cuando queremos hacer una transición que no se escucha al ver como giras la camara 


# 3. Zoom In, Zoom Out, Slide Up, Slide Down

Transacciones tipicas de zoom de quitarlo, 
- Consiguen despertar tu atención al instante.
- Usadas para hacer enfasis en algo o sacar una conclusión
- Usadas también para cambiar de visuales

# 4. Cambio de música

Cambiar la canción es perfecta cuando se junta con alguna transición de las anteriores.

# 5. Silencios inesperados o incomodos

- Un silencio rompe mucho la ilusión de que el video es rápido y caotico.
- Si se combina el silencio de Risers con silencio se crea un shock psicologico tan suave pero adecuado para muchas situaciones. 

# 6. Subtítulos

- Es mejor no subtitular todo el video, las partes más interesantes y estimulantes dejarlas sin texto, para que la atención del espectador se vaya a lo más importante. Y evitar que sea menos monotono.
- Un resultado más profesional se presenta de limpia

# 7. Transiciones ópticas

- Cuando se gira la cámara, se aplica un corte en la parte más rápida del giro.
