# Con Namelix

- Para empezar usamos diferentes cosas
- usar www.namelix.com que es un generador de nombres
- Usar el prompt en ChatGpt o Claulde el prompt:
```
PROMPT 2: Prompt para Namelix

Estoy buscando un nombre de marca para vender este producto [DESCRIPCIÓN DE TU PRODUCTO]. Usaré otra herramienta de IA para ayudar a generar ideas de dominios. Mi objetivo con esta marca es vender productos para [mascotas y perros en general, así que no tiene que limitarse únicamente a este dispositivo (ADAPTAR A TU PRODUCTO)]. Por favor, dame una larga lista de palabras clave que pueda ingresar en esta herramienta.

```

- Luego en namelix le damos en Brandeable names, luego next, random ideas. Luego le pongo las palabras claves en brand info
- Luego ir a godaddy  y ver si el nombre de la marca esta disponible
- Si no esta disponible le podemos poner un **THE** al inicio.

# Otra opcion con ChatGPT

usar este prompt 

```

Eres un experto en ecommerce. Ayúdame a buscar un nombre para mi marca. Mi producto es [DESCRIPCIÓN DEL PRODUCTO].  
  

Ayúdame a encontrar un nombre creativo, atractivo y memorable para mi marca. Dame al menos 10 sugerencias diferentes. Quiero que estos nombres:

- Sean fáciles de recordar y pronunciar.
    
- Funcionen bien en redes sociales, especialmente en anuncios de Facebook e Instagram.
    
- Estén disponibles como dominios web (o al menos suenen bien como dominios).
    

Además, dame una breve justificación de por qué cada nombre podría funcionar bien para atraer la atención de mi audiencia objetivo.

```
