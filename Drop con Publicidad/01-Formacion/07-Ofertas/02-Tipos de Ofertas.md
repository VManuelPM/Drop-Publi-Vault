# 1. % de Dto y Envío Gratis

- Esta saturado, pero lo suelen hacer todos los dropshippers promedio.
- Es una oferta muy normal y no diferencia de la competencia.

# 2. Descuento por cobrar envío

- Bajar el precio del producto y lo que he bajado del producto se cobra de envío.
- El precio anclaje es mucho mas bajo.
- Esto aumenta los añadidos al carrito, mas ventas, pero menos conversión.

# 3.  Dar regalos

- Otra estrategia es dar regalos que no cuestan nada.
- Se mejora el valor percibido del producto.
- Por ejemplo en una consola que viene con dos mandos -> Se dice que se regala un mando, pero ya viene
- Otro ejemplo -> Imagina el peluche que respira se dice: Hoy Luz gratis, pero ya viene.
- Poner regalos que no nos cuenten dinero.
- Normalmente Marc no da mas de dos.

# 4. Insertar Variantes del Producto

- Desglosar el producto.
- Con la consola, costaba 17$, la consola tenia 40.000 juegos solo habia eso, pero en la web, aparecia un regalo de 10.000 juegos. Ellos pusieron diferentes variantes de juegos. por ejemplo pusieron una variante de 1000 juegos luego una de 10.000 y luego una de 30.000. 
- Quien hace esto a la perfección es McDonalds, te ponen lo barato muy caro pero ellos lo inflan para que compres el caro.
- Si hay variantes de Color y talla **no se puede hacer esto**.

# 5. Ofertas por Cantidad

- Descuentos por cantidad.
- Muchos cometen el error de poner descuentos por cantidad cuando el producto no tiene sentido comprarse dos. 

# 6. Mínimo de Dinero para Envío Gratis Desbloqueado.

- Envío a partir de x cantidad

# 7.  BOGO: Buy One Get One

- No todos los productos permiten hacerlo, tenemos que tener margen suficiente para hacerlo.
